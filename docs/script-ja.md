# 発表原稿（日本語・約1分30秒）

## スライド 1

「好きなキャラクターで、勝敗のない熱いバトルを。」——これが私たちの作った *Photo Fighter* です。ブラウザだけで動く、1 対 1 の対人格闘ゲームです。

こだわったのは三つです。一つ目、相手は必ず人間であること。AI は強くてもいつかパターンになりますが、人間相手なら毎回予想外が起きて、そこに面白さが生まれます。

二つ目、キャラクターが世界に一つであること。写真を 1 枚アップロードすると、姿勢のキーポイントを自動検出し、背景を除去して、人物画像まるごとを骨格にバインドします。だから戦うのは汎用の棒人間ではなく「あなた自身」です。

三つ目、勝敗をなくしたことです。勝敗判定もランキングも段位もありません。残るのは、殴って、吹き飛ばして、壁で跳ねる——その気持ちよさだけです。

## スライド 2

そしてもう一つの狙いが、ソーシャルです。マッチングして 1 分間戦うと、申請も承認もなしに、双方が自動でフレンドになります。「フレンドになりませんか」ではなく「一緒に戦った」から関係が始まる、という設計です。

ただ、増え続ける一方では意味がありません。フレンドは 1 人 500 人まで。超えると、最後に一緒に戦ったりチャットした時刻が最も古い相手から自動で外れます。だからフレンド一覧は、常に「最近一緒に遊んでいる人」で埋まります。

技術面はシンプルです。戦闘ロジックは両者のブラウザで 60FPS の決定論シミュレーションとして動き、Supabase の Realtime が入力とホストのスナップショットを中継します。データベースはマッチング、フレンド、チャットだけを担当し、専用のゲームサーバーはありません。フロントは React と Phaser、静的ファイルとして GitHub Pages に自動デプロイしています。

PC でもスマホでも、URL を開けばすぐ遊べます。ぜひ一度、殴り合ってみてください。
