# フォトファイター Photo Fighter

**好きなキャラクターで、勝敗のない熱いバトルを。**

**オンラインで遊ぶ：https://lishuaihua2002.github.io/pvp/** （スマホのブラウザでそのまま遊べます。横画面推奨）

ブラウザで動く横スクロール 1v1 対人格闘ゲーム。写真を 1 枚アップロードすれば自分だけのファイターができ、友達やマッチングした相手と生身の人間同士で殴り合えます。

## このプロジェクトの目的

- **相手は必ず人間（PVP > PVE）**：AI 相手はいつかパターンになる。人間相手だからこそ予想外が生まれて面白い。だからオンラインマッチング・フレンド対戦・1 台での 2 人プレイ、すべて対人のみ。
- **キャラクターは世界に一つ**：自分の写真をアップロードすると姿勢のキーポイントを検出し、背景を除去して人物画像まるごとをスケルトンにバインドして動かします。汎用の棒人間ではなく「あなた自身」が戦います。
- **勝敗はない、気持ちよさだけ**：勝敗判定もランキングも段位もありません。攻撃は「インパクト値」として蓄積し、一定量を超えると相手は地面に倒れて寝そべり、また起き上がります。ゲージが満タンになれば必殺技で相手を吹き飛ばし、壁に当てて何度もバウンドさせられます。目的はただ一つ、戦っていて気持ちいいこと。
- **戦っているうちに友達になる**：連続で 1 分間戦うと、双方が自動でフレンドになります。申請も承認も不要。戦い終わればそのままチャットして、次の一戦を誘えます。「フレンド追加しませんか」ではなく「一緒に戦った」から関係が始まります。
- **フレンドには上限があり、関係は新陳代謝する**：1 人あたり最大 500 人。超えると最も活動が古いフレンド（最後に一緒に戦った／チャットした時刻が最も古い相手）から自動で外れます。フレンド一覧は常に「最近一緒に遊んでいる人」で埋まります。

## 遊び方と操作

- キーボード：`A/D` 移動 · `W/スペース` ジャンプ（空中でもう一度押すと 2 段ジャンプ） · `S` しゃがみ · `J` パンチ · `K` キック · `L` 必殺技 · `Esc` 退出
- 派生技：しゃがみ+パンチ = 下段ストレート · しゃがみ+キック = 足払い · 空中+パンチ = 昇龍拳 · 空中+キック = 飛び蹴り
- しゃがみはかなり低いので、立ちパンチは頭上を空振りします（足払いやキックは当たります）
- 必殺技：相手を 1 回ダウンさせるとゲージが満タン。`L`（スマホは ⚡ ボタン）で相手の位置にロックオンして突進し、当たれば相手を横向きに吹き飛ばし、壁で跳ね返り、着地してさらに数回バウンドします。ダメージは一切入らず、当たらなければ場外端まで突進し続けます。
- スマホ：バーチャルスティック（左右移動 / 上でジャンプ / 下でしゃがみ）と右側のボタンが自動表示されます
- ローカル 2 人プレイ（1 台）：P2 は `方向キー` + `1`(パンチ) `2`(キック) `3`(必殺技)
- 体力ゲージなし：攻撃は「インパクト値」として蓄積し、連続でもらうとダウンして寝そべり、起き上がり中は短時間無敵

## 機能一覧

- アカウント：メール登録／ログイン／パスワード再設定 + ゲストで即プレイ（Supabase 匿名ログイン）
- ファイター：プリセット 4 体 + 写真ファイターエディタ（ブラウザ内で圧縮・EXIF 除去、姿勢キーポイント検出、人物セグメンテーションで背景除去、画像まるごとのスケルトンバインド、アニメーションプレビュー、ローカル保存）
- バトル：60FPS の決定論的シミュレーション、ヒットストップ、画面シェイク、パーティクル、被弾フラッシュ、プロシージャル効果音
- マッチング：`try_matchmake` RPC によるアトミックなペアリング（`for update skip locked` で競合防止）
- オンライン：プライベート Realtime Channel（入力の Broadcast + ホストによる状態スナップショット + Presence で切断検知）
- ソーシャル：ユーザー検索／フレンド申請、ダイレクトメッセージ（サーバー側検証＋レート制限）、ブロック、1 分間の対戦で自動フレンド、フレンド上限 500 と非活動者の自動整理
- デモモード：QR コードで即プレイ、ゲスト入口、診断パネル

## 技術スタック

- フロントエンド：React 19 + TypeScript + Vite + Tailwind CSS 4 + Zustand
- ゲームエンジン：Phaser 3（スケルトンアニメーション + 写真ファイターのメッシュスキニング）
- ビジョン：MediaPipe Pose（姿勢キーポイント）+ 人物セグメンテーション（背景除去）
- バックエンド：Supabase（Auth / PostgreSQL / Storage / Realtime / RPC）
- サウンド：Web Audio API によるプロシージャル生成（権利リスクなし）
- テスト・検査：Vitest + oxlint

## ローカルで動かす

### 1. 必要環境

- Node.js >= 22.12（nvm 推奨）
- Supabase プロジェクト 1 つ（無料プランで可）

### 2. Supabase の設定

1. [supabase.com](https://supabase.com) でプロジェクトを作成。
2. SQL Editor で `supabase/migrations/*.sql` を番号順に実行（または `supabase db push`）。
3. Dashboard → Authentication：Email ログインを有効化し、**Anonymous Sign-Ins** も有効化（ゲストプレイに必須）。
4. Dashboard → Project Settings → API：Project URL と Publishable (anon) Key をコピー。

> ⚠️ フロントエンドで使えるのは Publishable/Anon Key のみです。service_role / Secret Key をフロントに書いたりリポジトリにコミットしないでください。

### 3. フロントエンドの起動

```bash
cd app
cp .env.example .env    # Supabase URL と anon key を記入
npm install
npm run dev             # ローカル開発
npm run dev:lan         # LAN 公開（スマホから QR で接続。HOW_TO_PLAY_LAN.md 参照）
```

### 4. その他のコマンド

```bash
npm run build       # 型チェック + 本番ビルド
npm run test        # 戦闘シミュレーションのユニットテスト
npm run lint        # oxlint
```

## セキュリティ設計

- 全テーブルで RLS を有効化。書き込みはすべて `security definer` の RPC 経由で検証
- Storage はプライベートバケット。パーツ画像は署名付き URL 経由で、対戦相手は試合中のみ参照可能
- Realtime はプライベートチャンネルを使用し、対戦する 2 人だけが参加可能
- チャットはプレーンテキストとして描画（React の標準エスケープ）。HTML は描画しない
- 高頻度の戦闘データは Realtime Broadcast のみで送り、DB には書かない

## 既知の制限

- フレンドの自動整理は「フレンド追加時／対戦による自動フレンド時」に走ります。バックグラウンドの定期実行ではありません
- 写真ファイターの切り抜き品質は元画像に依存します（全身・背景がシンプル・正面立ちが最適）
- オンラインは片方がホストとしてスナップショットを配信するため、遅延が大きい環境では引っかかりが出ることがあります
